## 📌 Giới Thiệu Tổng Quan

**Profile Premium** là website portfolio cá nhân được thiết kế và xây dựng theo chuẩn mực kỹ thuật cao cấp, dung hợp tinh hoa giữa hai lĩnh vực chuyên môn của tác giả:
1. **Kỹ thuật Công nghệ Ô tô:** Chẩn đoán điện tử ECU, giao thức mạng nội bộ xe hơi (CAN Bus, LIN, UDS ISO 14229), thu thập dữ liệu đo từ xa qua cổng OBD-II thời gian thực, nghiên cứu hệ thống truyền động xe điện (EV) và Hybrid.
2. **Kỹ thuật Phần mềm & AI:** Kiến trúc Microservices phân tán hiệu năng cao (Java Spring Boot, Python FastAPI, Node.js/TypeScript Express), trí tuệ nhân tạo thị giác máy tính & phân tích âm thanh chẩn đoán lỗi cơ khí (TensorFlow, PyTorch) và tích hợp các mô hình ngôn ngữ lớn (Google Gemini AI).

Website được thiết kế theo phong cách **Cyber-Automotive Dark / Light Mode**, hiệu ứng kính mờ (Glassmorphism), typography chuẩn quốc tế (*Rajdhani* và *Inter*), tích hợp các widget động: Chatbot AI đa tầng, widget thời tiết theo tọa độ GPS/thành phố thời gian thực và hệ thống bài viết nghiên cứu chuyên sâu.

## 🛠️ Ngăn Xếp Công Nghệ (Tech Stack)

### Frontend
- **Core:** React 18 (Hooks, Suspense, Concurrent Mode), TypeScript 5.7
- **Bundler & Tooling:** Vite 6
- **Styling:** Tailwind CSS 3.4, PostCSS, Autoprefixer, Custom Glassmorphism Utilities
- **Animation & Motion:** Framer Motion 11
- **Icons & UI Extras:** Lucide React, Canvas Confetti
- **Routing:** React Router DOM 6
- **Communication:** @emailjs/browser, Fetch API

### Backend Server
- **Runtime:** Node.js, Express 4.21
- **Language:** TypeScript qua `tsx` runtime
- **Security:** Helmet, CORS, Express-Rate-Limit
- **AI Integration:** Google Generative AI (Gemini 1.5 Flash REST API)
- **Deployment Strategy:** Tích hợp Static File Serving cho Single-page Application (SPA) production bundle

## ⚙️ Cài Đặt & Chạy Cục Bộ (Local Development)

### Yêu Cầu Tiên Quyết
- **Node.js:** v18.0.0 trở lên
- **npm:** v9.0.0 trở lên

### 1. Clone repository
```bash
git clone https://github.com/phamminhhieu2004/profile-premium.git
cd profile-premium
```

### 2. Cài đặt các gói phụ thuộc
```bash
npm install
```

### 3. Cấu hình biến môi trường
Sao chép file mẫu `.env.example` thành `.env`:
```bash
cp .env.example .env
```
Điền các giá trị nếu có:
```env
# Client
VITE_GEMINI_API_KEY=your_gemini_api_key_here
VITE_EMAILJS_SERVICE_ID=your_emailjs_service_id
VITE_EMAILJS_TEMPLATE_ID=your_emailjs_template_id
VITE_EMAILJS_PUBLIC_KEY=your_emailjs_public_key

# Backend
PORT=5000
NODE_ENV=development
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Khởi chạy
- **Chỉ chạy Frontend Development Server (Vite):**
  ```bash
  npm run dev
  ```
- **Chạy song song cả Frontend và Backend API Server:**
  ```bash
  npm run dev:all
  ```
- **Kiểm tra TypeScript & Xây dựng bản phát hành (Build Production):**
  ```bash
  npm run build
  ```
- **Chạy thử bản phát hành Frontend:**
  ```bash
  npm run preview
  ```

## 🚢 Hướng Dẫn Triển Khai Thực Tế (Deployment Guide)

### Cách 1: Triển khai Fullstack trên Render / Railway / VPS
Dự án được cấu hình sẵn để Express server phục vụ luôn file tĩnh từ thư mục `dist/`:
```bash
npm run build
npm run server
```
Server sẽ tự động lắng nghe tại cổng `PORT` (mặc định 5000) và phục vụ toàn bộ SPA cùng các API endpoints:
- `GET  /api/health` - Trạng thái hệ thống
- `POST /api/contact` - Tiếp nhận liên hệ (Rate limited)
- `POST /api/chat` - Trợ lý AI Gemini

### Cách 2: Triển khai Frontend trên Vercel / Netlify / Cloudflare Pages
- **Build command:** `npm run build`
- **Output directory:** `dist`
- Mọi route được tự động điều hướng về `index.html` cho SPA routing.
